Pause & record

Pausing a container stops CC routing inside it and records every site it sees, so you can add the ones you need to the config above. The toolbar button does the same for the container you are currently in. A pause ends when you resume it, or when the container's last tab closes.

Each host is listed with the URLs seen under it, as ready-made match: patterns — that is what a flow like an OAuth hand-off needs, where only /login/oauth/ has to be routed differently from the rest of the site. The method matters too: a POST can only be answered with inherit or ignore, since moving a tab re-issues the request as a GET and would drop the body. Query strings are never recorded.
